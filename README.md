# Israel Shmueli Landing Page

Static landing page for Adv. and Notary Israel Shmueli.

The site is built as a small SEO-focused Hebrew landing page for the search term `ישראל שמואלי`, with:

- `index.html` - full page markup, metadata, structured data and Hebrew content
- `styles.css` - responsive visual styling for GitHub Pages
- `robots.txt` and `sitemap.xml` - basic search indexing files
- `DEPLOY.md` - deployment notes

## Publishing

This repository can be published directly with GitHub Pages:

1. Open repository Settings.
2. Go to Pages.
3. Choose Source: `Deploy from a branch`.
4. Choose branch: `main`, folder: `/root`.
5. Save.

The temporary GitHub Pages URL will usually be:

`https://orid-maker.github.io/israel-shmueli-site/`

For best SEO, connect a custom domain later and update the canonical URL, sitemap and robots file to the final domain.

## SEO Note

No one can guarantee first position in Google, but the page was prepared with focused title tags, Hebrew headings, permanent text content, LegalService schema and contact details to improve indexing for Israel Shmueli.
